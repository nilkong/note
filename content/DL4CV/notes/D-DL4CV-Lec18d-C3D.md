# C3D: The VGG of 3D CNNs
## Feature

1. 3D CNN that uses all $3\times 3\times 3$ Conv and $2\times 2\times 2$ Pooling
2. The model weight is open source

## Problem

$3\times 3\times 3$ Conv is very expensive to run
